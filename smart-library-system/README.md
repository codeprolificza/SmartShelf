# Smart Library Management System

A capstone project for CSC 200/CSC 300 (joint group project).

## About
A web-based system for managing a book library, searching the catalog,
and getting personalized book recommendations.

## Pages
- `index.html` — Homepage
- `search.html` — Search books (coming soon)
- `recommendations.html` — Recommendations (coming soon)

## Folder Structure
- `css/` — stylesheets
- `js/` — JavaScript for interactivity
- `images/` — book covers, logo, icons
- `data/` — book data (e.g. books.json)
- `docs/` — project proposal and progress reports
